# API Testing Guide for Containerized Environment

## 1. Check if API is running
# Bash/Command Prompt:
curl http://localhost:8000/
# PowerShell:
Invoke-RestMethod -Uri http://localhost:8000/

## 2. Start a Chat Session (Non-streaming)
# Bash/Command Prompt:
curl -X POST http://localhost:8000/chat -H "Content-Type: application/json" -d '{"message": "Perform exploratory data analysis.", "thread_id": "test-1"}'

# PowerShell:
Invoke-RestMethod -Uri http://localhost:8000/chat -Method Post -ContentType "application/json" -Body '{"message": "Perform exploratory data analysis.", "thread_id": "test-1"}'

## 3. Approve a Proposal (Human-In-The-Loop)
# Use this when the status is "waiting_for_human_approval"
# Bash/Command Prompt:
curl -X POST http://localhost:8000/approve -H "Content-Type: application/json" -d '{"thread_id": "test-1"}'

# PowerShell:
Invoke-RestMethod -Uri http://localhost:8000/approve -Method Post -ContentType "application/json" -Body '{"thread_id": "test-1"}'

## 4. Run Automated Test Suite
# PowerShell:
./run_tests.ps1
