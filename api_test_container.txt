# API Testing Guide for Containerized Environment

## 1. Check if API is running
curl http://localhost:8000/

## 2. Start a Chat Session (Non-streaming)
curl -X POST http://localhost:8000/chat \
     -H "Content-Type: application/json" \
     -d '{
       "message": "Perform exploratory data analysis on the dataset to identify patterns.",
       "thread_id": "test-session-1"
     }'

## 3. Start a Streaming Session
curl -X POST http://localhost:8000/stream \
     -H "Content-Type: application/json" \
     -d '{
       "message": "Perform exploratory data analysis on the dataset to identify patterns.",
       "thread_id": "test-session-streaming"
     }'

## 4. Approve a Proposal (Human-In-The-Loop)
# Use this when the status is "waiting_for_human_approval"
curl -X POST http://localhost:8000/approve \
     -H "Content-Type: application/json" \
     -d '{
       "thread_id": "test-session-1"
     }'

## 5. Cancel a Proposal
curl -X POST http://localhost:8000/cancel \
     -H "Content-Type: application/json" \
     -d '{
       "thread_id": "test-session-1"
     }'
